GMU CES Booth Display — Techtopia

Overview

Role: Design + Fabrication Lead  ·  Location: George Mason University

What it is

A 6×6 ft interactive terrain map of Northern Virginia for GMU's Consumer Electronics Show booth. CNC-machined terrain panels with 40+ 3D-printed scaled building models representing local tech companies, with GMU as the central hub.

Fabrication

Precision CNC routing of the terrain base, 3D printing and detailing of all building models, integration of custom model train tracks and scenic elements.

Challenges

  • Large-format CNC — precise material handling and fixturing
  • Coordinating 40+ individual 3D printed parts
  • Tight trade show deadline

Wood CNC Feeds & Speeds Calculator

Overview

Role: Developer  ·  Location: MIX Fab Lab, GMU

Problem

CNC operators needed a quick, reliable way to calculate feeds and speeds for wood machining across different species and tool configurations — something fast enough to use on the shop floor.

Solution

Web-based calculator for RPM, feed rate, chip load, and material removal rate. Designed specifically for the routers at the MIX.

Features

  • Multiple wood species with pre-configured material properties
  • Tool library with common endmill configurations
  • Clean interface built for shop-floor use

Metal CNC Feeds & Speeds Calculator

Overview

Role: Developer  ·  Location: MIX Fab Lab, GMU

Problem

Metal machining requires more precise calculations than wood — harder materials, higher cutting forces, greater risk of tool breakage. The MIX needed a dedicated calculator for metal operations.

Solution

Calculator supporting aluminum, mild steel, stainless steel, and brass with SFM-based spindle speed, feed rate, chip load, and coolant recommendations per material.

Features

  • SFM values for common metals
  • Coolant and tooling recommendations
  • Safety guidelines for metal machining

E-Paper Weather Display

Overview

Low-power weather display using a 7.5" Waveshare e-paper screen with an ESP32 microcontroller showing live weather data.

Challenge

The V2 Waveshare display had persistent ghosting issues not documented in standard guides — required digging into the hardware initialization sequence to fix.

Solution

Custom code in VS Code with PlatformIO, implementing hardware-specific initialization to eliminate ghosting. Documented the V2-specific fix for the community.

What I Learned

Hardware version differences matter. Systematic debugging and clear documentation save a lot of time — for yourself and everyone else.

Rosie Wildlife Tracker 🏆

Award

3rd Place — GMU Hackfax 2025, "A Better World" Theme

Overview

Compact, non-invasive wildlife tracker with ESP32, GPS, accelerometer, and pulse sensor. Monitors location, movement, and heart rate in real time.

Technical Details

  • ESP32 for data collection and wireless transmission
  • GY-521 accelerometer/gyroscope for movement tracking
  • Pulse sensor for stress/heart rate monitoring
  • GPS for real-time location
  • 3D-printed animal-mountable enclosure (100×70 mm)
  • Wireless data via Oracle Cloud

Green Heart Monitor 💚

Award

Winner — GMU HackOverflow 2025 Beginner's Track

Overview

Portable Arduino Nano ESP32 device for real-time environmental and health monitoring with a live web dashboard.

Features

  • Multi-sensor: water level, light, humidity, temperature, GPS, heartbeat
  • HTTP server delivers live data to any browser on the same network
  • SoftAP mode — ESP32 hosts its own WiFi network
  • OLED display for on-device readout
